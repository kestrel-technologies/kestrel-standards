# kestrel-standards

Source of Charter. Edit via CL; EntSec Governance and the Office of the CTO are code owners.

Every page here is published to Charter, Kestrel's standards portal, by the Charter generator, which reads `charter.yaml` for titles and navigation order. Change a standard by opening a CL against `main`; the code owners in `.github/CODEOWNERS` review it.
---

Kestrel Technologies is a fictional company created for an educational workshop. Nothing in this repository is a real credential, person or product. Mirrored from Roost by `roost-mirror`; CL metadata is preserved in commit trailers (`Roost-CL:`, `Reviewed-by:`).
